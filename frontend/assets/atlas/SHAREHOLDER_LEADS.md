# 股东关联专利线索维护

Operate 局部扩展，继承既有视觉系统；采用平面证据列表，不新增全站视觉规则。

`enterprise.html` 加载静态数据及 `shareholder-leads.js/.css`。`enterprise-directory.js` 的“股东线索”按钮展开内嵌面板；`enterprise.js` 在画像自有专利下接入同一组件。

按用户要求精简为“股东可能关联专利”：仅展示专利标题、公开号、最早优先权日，头部显示总数和“待核验”标记。股权路径、来源和匹配说明留在原核验报告中，不在前端展开。

候选按专利族去重，始终标记待核验，不计入自有专利。姓名同名不是身份或专利迁移证据；企业名称候选不可自动归属。

每页10族，超过10族才显示分页。已移除搜索、筛选和导出控件；无收录数据隐藏面板，已收录但未命中显示空状态。

正文14px、标题22px、辅助13px，蓝色控件、暖白底面。640px及以下标题18px、公开号和日期纵排，长文本换行。

在 `incopat` 目录更新静态数据：

```sh
python3 tools/build_shareholder_frontend.py --date 20260916
```
